World Draft lifecycle

Build here. Finish setup locally. Launch when ready.

A browser-generated `.rsdwl` imports as a visible World Draft. Dragonwilds Sync validates it, creates fresh local credentials, safely stages any included save, and opens a resumable Finish World Setup wizard when you open, start, or first-launch that World. The server does not run until required setup is complete.
