Experimental codename: Complete Authoring Tools

RuneSchema 0.6.3 Experimental Complete Authoring Tools

A community experiment built on official RuneSchema 0.6.0. It preserves the official loaders and spawn foundation, then adds a five-page UE4SS management interface, deterministic mod ordering, collision reports, authoring tools, spawn scale, explicit drop multiplication, and registry-safe identity overrides.

REQUIRED UE4SS PACKAGEv3.0.1-941-g0bfec09e

This is the only UE4SS download intended for this RuneSchema build. It preserves the original compatible binary and includes DoEarlyScan = 1, the Unreal Engine 5.6 override, disabled hot reload, and the stable UObject-array cache setting.

Source is maintained on GitHub: review the current 0.6.3 source on main, the historical experimental branch, or the draft upstream pull request. The prerelease provides the installable RuneSchema mod and its separately packaged matching UE4SS runtime.

Feature map

Official foundation. Experimental control layer.

OFFICIAL 0.6.0

RuneSchema baseline

  • Core loadersAssets, Blueprints, tables, recipes, spawns, strings, journals, courses, buildings, and enums.
  • Spawn foundationPersistent Actor, AISpawnPoint, RemoveActor, respawn, streaming, and orphan cleanup.
  • Mod orderContent folders follow directory discovery order.
  • UE4SS panelSchema-generation control.
  • Schema outputUtility, enum, and raw data-table schemas.
  • Scale and dropsNo spawn Scale or drop multiplier fields.
+
0.6.3 EXPERIMENTAL

Management and authoring layer

  • Formats preservedExisting official loaders and mod JSON remain the compatibility target.
  • Five-page interfaceOverview, Settings, Generators, Load Order, and Compatibility.
  • Deterministic ordermods.txt enable switches, Up/Down controls, comments, and saved order.
  • Collision reportsOptional scans for shared targets, properties, and full-array replacement.
  • Authoring toolsSelectable Utility plus schemas for every JSON loader: assets, blueprints, buildings, courses, enums, journal, raw, recipes, spawns, and strings; FModel path normalization; and optional sanitized drafts.
  • Explicit spawn extensionsActor and AI Scale plus opt-in DropIncreasePercent, independent of size.
  • Registry-safe identityOptional unique PersistenceID and InternalName for assets, recipes, and journals.

RuneSchema 0.6.3 Experimental

Installation guide

Install the included folder directly inside UE4SS Mods. Do not rename the singular config directory.

  1. Download the package.Select Download 0.6.3 Experimental on the Modding page and extract the ZIP.
  2. Find the included RuneSchema folder.The package contains only the installable mod folder; source and technical documentation remain on GitHub.
  3. Copy RuneSchema into UE4SS Mods.Use the exact destination below. Merge or replace an older RuneSchema folder only after backing up any custom configuration.
  4. Launch Dragonwilds.RuneSchema can reconcile discovered content folders into mods.txt when the included tooling options remain enabled.

Required destination

RSDragonwilds/Binaries/Win64/ue4ss/Mods/RuneSchema/

Expected folder layout

RuneSchema/
|-- enabled.txt
|-- dlls/
|   `-- main.dll
|-- config/
|   `-- config.json
`-- mods/
    `-- mods.txt
Important: the folder is named config, singular. RuneSchema will not read it correctly if it is renamed to configs.

Adding RuneSchema content mods

Place each content mod in RuneSchema/mods/<Mod Name>/. The variant can add newly discovered folders to mods.txt, preserve comments, remove stale entries, and use alphabetical fallback ordering.

Feature-by-feature comparison

0.6.3 Experimental keeps the official loaders and normal folder-based content-mod structure, then adds an optional management and authoring layer around them.

Independent community experiment: the baseline is official RuneSchema 0.6.0, commit c36d894b02eb006fafc079325035b924ac49f28d, by UnskippableCutscene. The published prerelease is 0.6.3-experimental.1 and identifies at runtime as 0.6.3 Experimental. It is not authored, endorsed, maintained, or supported by the original author. Important boundaries

  • Scale changes size only; it does not automatically change drops, health, damage, navigation, or animation.
  • Drop multiplication has its own master switch and only affects supported live ItemsToDrop rows.
  • The compatibility report is advisory and cannot identify every semantic gameplay conflict.
  • Generated schemas and FModel snippets remain drafts that require author review.
  • Explicit identity values must be unique and stable; blank or omitted values preserve the loaded/default identity.
  • Load-order changes apply on the next RuneSchema load or restart.
